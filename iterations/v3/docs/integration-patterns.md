# Integration Patterns

## Pattern 1: Governance Integration (agent-orchestration + system-quality-security)
- Hook points in agent-orchestration coordinator
- Verdict enrichment with system-quality-security validation
- Debate protocol hooks across governance crates

## Pattern 2: Worker Integration (agent-workers)
- Pre/during/post execution hooks in agent-workers
- Resource allocation + monitoring via system-resources
- MCP-based communication protocols

## Pattern 3: Research Integration (agent-research)
- Context synthesis for claim verification via agent-research
- Evidence gathering for debate and validation
- Knowledge integration with agent-memory

## Pattern 4: Infrastructure Integration
- **data-infrastructure**: Persistence and API interfaces
- **system-observability**: Monitoring and alerting
- **system-resilience**: Fault tolerance and recovery
- **system-quality-security**: Provenance tracking and compliance

## Pattern 5: Cross-Crate Communication
- **agent-agency-contracts**: Standardized interfaces between crates
- **system-configuration**: Shared configuration management
- **development-tools**: Integration testing and validation
