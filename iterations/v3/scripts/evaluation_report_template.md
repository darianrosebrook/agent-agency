## Metric Definitions

### Agent Success Rate

```
agent_success_rate = successes / (total - infrastructure_failures - spec_failures)
```

**Interpretation**: What percentage of tasks that actually reached the agent were completed successfully?

**Excludes**: Infrastructure failures and task specification issues (not agent's fault).

### Completion Rate

```
completion_rate = (successes + agent_failures + council_rejections) / total
```

**Interpretation**: What percentage of tasks actually reached the agent for execution?

**Indicates**: Infrastructure health and task routing effectiveness.

### Quality Score

```
quality_score = average(caws_compliance, code_quality, test_coverage) for successful tasks
```

**Interpretation**: How good is the work produced by the agent?

**Components**:
- CAWS compliance (0-100%)
- Code quality metrics
- Test coverage

### Correctness Rate

```
correctness_rate = successes / (successes + agent_failures)
```

**Interpretation**: Of tasks the agent attempted, what percentage were correct?

**Excludes**: Council rejections (may be council strictness, not agent issue).

## Report Generation

Reports are automatically generated by `evaluate_harness.sh`:

- **JSON Report**: `evaluation_TIMESTAMP.json` - Machine-readable full data
- **Markdown Report**: `evaluation_report_TIMESTAMP.md` - Human-readable summary

### Generating Custom Reports

```bash
# Full evaluation with all complexity levels
./evaluate_harness.sh

# Only simple tasks (baseline)
./evaluate_harness.sh --complexity simple

# Skip pre-flight checks (not recommended)
./evaluate_harness.sh --skip-preflight
```
